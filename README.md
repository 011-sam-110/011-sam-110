CS-with-AI student at the University of Sussex who builds live-data web apps and real-time computer-vision tools: a satellite globe streaming ~12,000 open traffic cameras, a camera that tracks and recognises people, and a note-taking app for students.

## 🔭 Currently building

- **[turingDNA](https://turingdna.com)** - co-founder on a CRISPR guide-design platform. Live at turingdna.com; the repo is private.
- **[Unote](https://github.com/011-sam-110/Folio)** - a note-taking app for university students, [live](https://unote-six.vercel.app). Block editor with wikilinks and backlinks, Postgres full-text search, SM-2 spaced-repetition flashcards, infinite canvas boards with pressure-sensitive stylus ink, and lecture import that turns an MP4 into slides plus a timestamped transcript. 176 server tests. Currently rebuilding the landing page and adding a note action bar.
- **[Realtime AI Tracking Camera](https://github.com/011-sam-110/Realtime-AI-tracking-camera-with-raspberry-pi3-)** - a pan camera that follows and recognises people. A Raspberry Pi "head" streams video to a laptop "brain" that runs GPU face-recognition and real-time tracking, with a live React dashboard. Working rig; iterating on the edge/brain split.
